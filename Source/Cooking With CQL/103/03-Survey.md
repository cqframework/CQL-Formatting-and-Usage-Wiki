# Patterns

As the set of published material grows, there are multiple places where CQL best-practices, conformance requirements, and patterns are documented:

* The CQL Specification itself, especially the Author's Guide and Developer's Guide
* The Using CQL With FHIR implementation guide
* The CQL Common Artifacts for FHIR, US-based
* The Quality Measure IG, Using CQL page

To consolidate the guidance and facilitate discovery and access, the draft [CMS Quality Measure Development IG](https://build.fhir.org/ig/cqframework/cms-qmd/) has an "Authoring Guidance" topic that contains:

* Pattern Index: An overall index of patterns, conventions, and best-practices that provides measure developers with a single view of CQL authoring guidance
* US Quality Core Update Process: Documentation for how to refactor a QI Core 6 measure to use US Quality Core 0.5.0
* Refactored Index: An index of where common content landed in the refactor from QI Core 6 to US Quality Core 0.5.0

Where a topic is discussed in a published IG, the index links to it directly. Otherwise, the topic is linked and discussed in the Quality Measure Development IG.

> NOTE: The QI Core Authoring Patterns in the CQL Formatting and Usage Wiki have been moved into the draft CMS Quality Measure Development IG and will be maintained there going forward.
